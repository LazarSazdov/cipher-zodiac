Cipher Zodiac

A homophonic substitution cipher for the English alphabet. Type some text and compare three encodings. A monoalphabetic swap keeps the uneven letter distribution, so it can be broken by frequency analysis. The homophonic cipher spreads each letter across several symbols based on English letter frequency, which flattens the output distribution and hides those clues.
